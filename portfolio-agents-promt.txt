ПРОМТ: Создание лендинга-портфолио специалиста по вайбкодингу (HERO + «Избранные проекты» + «Что я делаю» + «Как я работаю» + CTA «Обсудить проект»)

Создай с нуля одностраничный лендинг-портфолио вайбкодера. Работай строго по описанию ниже, ничего лишнего не добавляй и существующие секции не переписывай.

1. СТАК И ИНСТРУМЕНТЫ
- TanStack Start (SSR) + TanStack Router, React 19, TypeScript, Vite 8.
- Tailwind CSS v4 (через @tailwindcss/vite), шрифт Manrope (400–800) подключается в root-layout ссылкой на Google Fonts.
- UI-кит shadcn/ui (компоненты в src/components/ui), lucide-react для иконок.
- Инструменты качества: ESLint (typescript-eslint + prettier-plugin) и Vitest + Testing Library.
- Язык интерфейса — русский.

2. СТРУКТУРА ПРОЕКТА
